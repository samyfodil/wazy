Every page in this section walks through a program that exists in the repository and runs in CI.
Nothing here is a sketch: the guests are real `.wasm` files built by real toolchains, and the host
code is the file you can open beside it.

```bash
git clone https://github.com/samyfodil/wazy && cd wazy
make test.examples
```

That builds nothing and downloads nothing — the guest binaries are committed. Each tutorial also
gives the command for its own example alone, and the toolchain command that produced its guest if
you want to rebuild it.

## Core WebAssembly

Start here if you have a `.wasm` and a Go program and want them talking. These examples use plain
core modules: the interface is integers and a linear memory, and both sides agree on the layout by
hand.

## The Component Model

A component carries its own typed interface, so values cross as Go values and the hand-agreed
layout above disappears. These four are the reason wazy exists as something other than a wazero
fork.
